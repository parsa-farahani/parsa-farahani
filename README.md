## 🚀 Featured Projects

### [Andromeda](https://github.com/parsa-farahani/andromeda-social-app) · [Live demo](https://andromeda-social-app-vercel-tau.vercel.app/)
Full-stack social platform built with **Next.js (App Router), TypeScript and MongoDB**.

- Posts, nested comment threads, likes, and search by title and `#tags`
- Admin panel with analytics charts and moderation tools (bans, cascading deletes)
- JWT access and refresh tokens with silent renewal in `proxy.ts`, HTTP-only cookies, and server-side authorization on every action
- Streaming UI with Suspense, cursor-based infinite scroll, secure image uploads (magic-byte validation)
- The README documents real problems I hit and how I solved them

`Next.js` `React` `TypeScript` `MongoDB` `Tailwind` `shadcn/ui` `Vitest`

### [Digikala Clone](https://github.com/parsa-farahani/digikala-clone) · [Live demo](https://digikala-clone-theta.vercel.app)
Responsive e-commerce app with **Next.js, Redux Toolkit, React Query and Appwrite**.

- Product pages with image carousels, ratings, comments and questions
- Cart that works for guests (Redux + localStorage) and merges into a server-side cart on login
- Optimistic updates for cart and reactions, URL-driven search filters with infinite scroll
- Login and signup as intercepting-route modals, protected routes with middleware

`Next.js` `TypeScript` `Redux Toolkit` `TanStack Query` `Appwrite` `Tailwind`

### Asteroid · Social App
React + TypeScript social app built three times with different state-management approaches: **Redux Core, Redux Toolkit (AsyncThunk) and RTK Query**, using MUI, Formik + Yup and Axios.
